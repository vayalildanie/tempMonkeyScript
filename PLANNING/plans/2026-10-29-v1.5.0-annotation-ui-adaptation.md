**Goal:** Adapt scoring, submit checking, and Remark Composer to the new per-translation annotation UI and prove the requested paths with a Playwright fixture.

**Architecture:** Keep the five existing userscript modules and add a reduced annotation fixture plus a small cascader/submit simulator. Test-drive shared parsing, scoring, submit behavior, and a narrow Remark Composer target/quote flow. Do not add a production build step.

**Tech Stack:** Plain JavaScript userscript modules, Playwright Test, Node.js, and a static HTML fixture derived from the supplied NOVA outerHTML.

**Spec:** [PLANNING/specs/2026-10-29-v1.5.0-annotation-ui-adaptation-design.md](../specs/2026-10-29-v1.5.0-annotation-ui-adaptation-design.md)

## Global Constraints

- Work only in the `v1.5.0-ui-adaptation` worktree; do not merge or push without user confirmation.
- Do not edit `README.md`.
- Do not change QC Compare behavior or selectors.
- Do not change `TransCursor` unless a failing test proves its number-based behavior is wrong.
- Accept optional whitespace only in `Trans N` module-name parsing; do not broaden other selectors.
- Initial target is the first populated translation whose displayed score does not begin with `3 Points`; fall back to Trans1.
- The first ArrowUp from that initial target jumps to Trans1; later movement is sequential and clamped.
- If the composer is closed, `Q` opens it using the initial-target rule, then appends the quote. If open, `Q` appends to the highlighted target.
- Remove title-click references completely.
- Automated Remark Composer coverage stays focused; broader button usability is user feedback.
- Bump both `@version` and `TL.SCRIPT_VERSION` to `1.5.0` together.
- A live-page Submit Check smoke test remains mandatory after fixture tests.

## Review Focus

- Empty score does not begin with `3 Points`, so it is an eligible initial target; Task 5 tests this.
- A fully labeled `2 Points / …` remains eligible and likely-remark; Task 5 tests this.
- A failed label click must not advance merely because `2 Points` is already displayed; Task 3 tests this.
- Synthetic Space must activate the fixture submit handler exactly once, not merely be dispatched; Task 4 tests this.
- Title clicks must neither insert text nor move the target; Task 5 tests this.
