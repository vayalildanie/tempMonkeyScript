# v1.5.3 Implementation Plan: Remark Gate, Escape, Quote Rework, and QC Compare Overhaul

> **Status:** Ready for development. Every open decision has a default in the Decision Register; the lead applies the default unless the user overrides it before the dependent task starts. Nothing here is implemented yet.
>
> **Spec:** `PLANNING/specs/2026-10-29-submit-check-non3-remarks-design.md`. This plan supersedes the spec where they differ (notably the quote format: see A-QUOTE).

**Goal:** One v1.5.3 release with two independent tracks.

- **Track A, annotation stage (`src/remark-composer.js`):** hold Submit Check and Label Check when a populated non-3 translation has no remark; let Escape blur a remark box before closing; rework `Q` so quotes carry no source reference, accept the Note field, and refuse any selection that is not inside exactly one source element.
- **Track B, QC Compare (`src/qc-compare.js`):** Z swaps Score and Remark together with a preserved-pair failsafe and auto-advance; the selector spans Score and Remark; dead Rewrite and whole-row Remarks code is removed; a QC test suite is added.
- **Clean-up and release:** consolidate the test suite, then release with the checklist in Task 7.

**Tech stack:** Plain JavaScript userscript modules loaded through `@require` from `main`, Playwright tests, reduced fixtures built from user captures.

### Task 4: Quote rework (Lead)

Requirement: A-QUOTE. Decisions: Q1, Q2, Q3. Supersedes the spec's `Note "…"` format.

**Behavior**

- The token is exactly `"text"`: `Utils.stripAnnotationTags(selection).trim()` wrapped in double quotes. No `Trans N` or `Note` prefix anywhere.
- Quotable content roots (Q1):
  - translation: `.preview-content` inside a module whose name matches `^Trans ?\d+$`;
  - Note: `.ant-spin-container` inside `[data-module-key="NoteTrans"]`.
- **Single-source rule.** A private helper `quoteSource(range)`:
  1. collects the quotable content roots that intersect the range, de-duplicated, dropping any root contained in another (nested wrappers);
  2. clamps a copy of the range to each root and keeps the roots whose clamped text is non-empty after stripping;
  3. accepts only when exactly one root remains **and** the whole selection's text equals that root's clamped text, both normalized with `stripAnnotationTags`, collapsed whitespace, and trim.
- Consequences: Ctrl-A, a span across two translations, Note plus a translation, Context-EN plus a translation, and a selection that includes a title are refused. Dragging a whole translation and releasing in the blank space below it is accepted, because the extra range adds no text (the v1.3.3 boundary quirk).
- Refusal writes nothing, keeps the selection, and shows the hint `Select text inside one translation or the Note to quote it.`
- No selection: unchanged (focus `#rmd-edit`, caret at end); the hint wording drops "translation-only": `Select text in a translation or the Note first to quote it.`
- Routing is unchanged: closed composer opens at the initial target first; an open composer writes to the highlighted target; the target never moves.
- Separators (Q3): a previous quote is recognized when the trimmed tail ends with a double-quoted span (`/"[^"\n]*"$/`). Rules unchanged: quote then phrase `": "`, phrase then phrase `", "`, anything then quote two spaces.

## Track B: QC Compare

### Current behavior being changed

- **Z** swaps only the score, and the old `adopted` map remembers Annotator 1's prior value for Undo. After a successful apply it calls `advanceFocus()`; undo does not advance.
- **Selector** outlines only the Score's `.cascade-container` (`.qc-active-score`).
- **Arrows** go through `advanceFocus()` and the dead `extraSel` layer; Left/Right toggle columns through `TransCursor`.
- **Badge** (`renderBadges`, `:772`) sits under each Score, between it and the Remarks module: `≠ Annotator 2: <score> Swap →`, or `✓ Swapped to Annotator 2 · was: … Undo`. Its position must not change.

### Target behavior

**Z swaps Score and Remark (B-Z)**

- Z on the selected translation, Annotator 1's tab, writes the other side's Score and Remark as one unit. If only one half differs, only that half is written.
- The remark write replaces the whole text through `Utils.setNativeValue`, so NOVA's input events fire.
- X, C, 3, 2, and the digit keys change the score only, never the remark.
- Mouse `Swap →` and the badge's Undo do the same flip as Z but never move the selector.

**Preserved pair and flip-flop (B-FAIL)**

- On each row's first scrape, store per translation `{ a: {score, remark}, b: {score, remark} }` from the two tabs. Memory only; discarded on a row change.
- A re-scrape, the stale-text verify poll (`:739`), a tab switch, a platform re-render, X, the clear icon, or a hand edit never empties or replaces a stored value.
- Z compares the live unit (score and remark) to the pair: matches `a` writes `b`; matches `b` writes `a`; matches neither (cleared, half-cleared, or edited) writes `b`, and the next Z writes `a`.
- Before Z overwrites a live unit that matches neither side, the live text is stashed in a per-translation `manual` slot and shown as `was:` in the badge (B8). It is not part of the flip-flop.
- Z reads the pair, not the live Annotator 2 tab, so clearing Annotator 2's data on its tab does not stop Z.
- Refusals (no write, no advance, status message): Annotator 2's tab active; the target side's score is empty (B9); both sides identical (B4).

**Auto-advance (B-ADV)**

- Every Z that writes advances with `cursor.step(1)` once the writes settle: same order as ArrowDown, skipping translations that are not scoreable, and staying put on the last scoreable translation (B3). To flip a translation back: Up, then Z.

**Selector (B-SEL)**

- `onChange` marks the Score's `.cascade-container` and the translation's Remarks module (`.qc-active-remark`, same look). The badge DOM position is unchanged. `cursor.sync()` restores both outlines after a re-render.
- Arrows stay translation-based. Selecting a translation always selects both halves; there is no separate Remark stop. `Utils.inTextEntry()` still disables every shortcut while a textarea has focus.

**Removal (B-RW)**

- Delete: `TEXT_FIELDS`; `adoptFieldText`, `undoFieldText`, `adoptedText`, the `textA`/`textB` long-text snapshots; `rewriteAvailable`, `extList`, `sameExt`, `selectExt`, `reapplyExtHighlight`, `extraSel`; the Rewrite and whole-row Remarks compare boxes in `renderTextCompare` and their CSS; `appendRemarkLine`, `splitRemarkLines`, `remarkAddLines`, `.qc-tb-append`; the overlay (`ensureHLOverlay`, `syncHLOverlay`, `syncFieldHighlights`, `HL_COPY`, `highlightTrans`, `TRANS_REF_RE`, `numsInRef`, `referencedTransNums`) and the input/scroll listeners feeding it; `rewriteDiff` in `updateSummary`; the Rewrite leg of every selector; the Rewrite and "+ Add" click branches in the document click handler.
- `advanceFocus()` collapses to `cursor.step(1)`.
- Rework `get3PtRemarkViolations()` to the per-translation rule (B5).
- Help text (`:1249`) becomes `Z Swaps Score + Remark`; the arrow hint becomes `Move Focus (Trans)`.
- Done when `grep -ni rewrite src` returns only historical comments the lead accepts, and no deleted name is referenced anywhere.
