# v1.4.1 Closed-state Check-Icon Pills Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give Remark Options a scoreShortcuts-style pill that shows when it's closed (displaying the current Check Icon), add a matching read-only pill to QC Compare shown when its Legend is closed, and document the quote-insertion flow in place — all without changing quote/check behavior itself.

**Architecture:** Two independent, same-shaped UI additions (one per module) sharing a visual pattern already established by `scoring-shortcuts.js`'s `#tl-score-pill` (fixed-position button, hidden/shown based on existing open/closed state, styled from a small mode→{text,bg,fg,border} lookup table). Remark Options' pill is a live control (click = open); QC Compare's pill is read-only (reflects localStorage only, since Remark Composer never runs on `/quality_` pages).

**Tech Stack:** Plain userscript JS (Tampermonkey `@require` chain), no build step, no test framework. `node --check` is used per task as an objective syntax-verification substitute for a test run.

**Spec:** [docs/superpowers/specs/2026-08-27-v1.4.1-closed-state-pills-design.md](../specs/2026-08-27-v1.4.1-closed-state-pills-design.md)

## Global Constraints

- Work directly on the `main` branch, in the existing working tree. Do **not** create a worktree or a feature branch.
- Do **not** commit after individual tasks. Only the single, final step of Task 5 creates a commit, covering every change made across all five tasks.
- No behavior change to the quote-insertion logic (`tryQuoteSelection`/`appendToken`) or to the submit-check logic (`performCheck`/`cycleCheckMode`) — this release only adds comments and two new pills.
- No new keyboard shortcuts. The pills are mouse-only affordances; `O` continues to be the only key that opens Remark Options (`remark-composer.js:841`), and QC Compare's `O` continues to only toggle its Legend (`qc-compare.js:1400-1402`).
- Reuse the exact CSS idiom of `scoring-shortcuts.js`'s `#tl-score-pill` (`scoring-shortcuts.js:792-795`): `position:fixed; left:16px; ...; z-index:2147483647; font:12px/1 -apple-system,"Segoe UI",sans-serif; font-weight:700; border-radius:18px; padding:8px 13px; box-shadow:0 2px 10px rgba(0,0,0,.12);`.
